# Blockchain Record Management System

## Project Overview
This project is a blockchain-based record management system developed using Solidity, Truffle, Ganache, MetaMask and HTML, CSS and JavaScript.

It allows users to add, view and update records through a website while storing the records on the blockchain.

## Technologies Used
- Solidity
- Truffle
- Ganache
- MetaMask
- HTML
- CSS
- JavaScript
- Ethers.js

## Setup Instructions
1. Install Node.js and Truffle.
2. Open the project folder in VS Code.
3. Start Ganache Quickstart.
4. Connect MetaMask to the local Ganache network.
5. Open the terminal in VS Code.
6. Run `truffle compile`.
7. Run `truffle migrate --network development`.
8. Update the contract address in `frontend/script.js` if required.
9. Open the frontend using VS Code Live Server.

## Features
- Connect MetaMask wallet.
- Add blockchain records.
- View existing records.
- Update existing records.
- Store transactions on the blockchain.
